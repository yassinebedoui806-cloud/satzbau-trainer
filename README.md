# Satzbau Trainer

Ein kleines Python-Programm, mit dem ich deutsche Satzbildung übe:
Kasus, Verben mit Präpositionen, Konnektoren und Relativsätze.

Ich übersetze Sätze vom Englischen ins Deutsche, das Programm prüft die Antwort,
speichert meine Fehler nach Kategorie und wiederholt schwache Sätze öfter
(Lernboxen-System, Leitner-Prinzip).

## Benutzung
    python main.py

## Funktionen
- 10 zufällige Sätze pro Runde, schwache Sätze kommen öfter
- Fehlerstatistik nach Kategorie (gespeichert in progress.json)
- Umlaute können als ae/oe/ue eingegeben werden

## Ziel
Mein Deutsch von B1 auf B2 (telc) verbessern und dabei Python üben.

## English
A small Python tool to practice German sentence building. It tracks mistakes by
category and repeats weak sentences more often using a Leitner box system.
Run with `python main.py`.
